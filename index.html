Features

🔒

Secure Connections

Full SSH2 protocol support via dartssh2. Password authentication with secure credential storage.

⌨

Full Terminal Emulator

Complete xterm-compatible terminal with 256-color support, resizable PTY, and smooth rendering.

⌨

Mobile Keyboard Overlay

Extra key row with ESC, TAB, CTRL, ALT, arrow keys, and special characters. Sticky modifier support.

💾

Connection Manager

Save, edit, and organize your server connections. Quick connect for one-off sessions.

🎨

Material You Theming

Dynamic color support that adapts to your device wallpaper with Material 3 design.

⚡

Lightweight & Fast

Built with Flutter for native performance on both Android and iOS with a single codebase.
